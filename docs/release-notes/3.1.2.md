# ATO 3.1.2

Two fixes in the popup.

## Closing protects only the tab you're looking at

- Closing search results, a site, a selection or a window used to skip the current tab of every window. Search for a page you have open in several windows, and if it was the front tab in each, Close left all of them open: "Nothing to close — 7 tabs protected".
- Now only the current tab of the window you're in stays. The front tabs of your other windows close like any other tab.
- Closing a window from the Windows view now includes its front tab, so a window with nothing protected left closes entirely.
- Duplicate cleanup and the tab right-click menu are unchanged: they still keep the current tab of every window, so they never close a page you have showing somewhere.
- Tabs playing sound, split views, and (by default) pinned and grouped tabs are protected as before.

## ↓ from search steps into the results

- With a query (or a `url:` chip) in search, ↓ now moves into the results, where ⌫ and Delete close the row under the cursor. Typing a letter goes back to search with it. ⌘⌫ from the field still closes every result.

## Installing

ATO needs Chrome 157 or newer. The Chrome Web Store copy updates on its own. To build it yourself: `npm install && npm run build`, then load `dist/` as an unpacked extension.
