# ATO 3.2.0

The popup now says why it left tabs open, and why something failed. Three smaller fixes come with it.

## Why tabs were kept

- A close that leaves tabs open now says why, tab by tab: "Closed 5 tabs · kept the current tab, 1 playing, 2 pinned". Before, it only said "kept 3 protected".
- The reasons are the current tab, playing sound, split view, pinned, in a group, and, for duplicate cleanup, the last copy of a page.
- The same goes when nothing closes: "Nothing to close — kept 2 pinned".
- Nothing about what closes has changed, only what the popup tells you.

## Why something failed

- When Chrome refuses something and its error has a plain reason, the popup says it: "Couldn’t close tabs: finish dragging the tab, then try again". This covers closing, undo, moving, switching tabs and windows, unloading and muting.
- Otherwise it says what failed, and to try again.
- A longer message makes the notice taller instead of running out of it.

## Fixes

- **Poster theme:** on the highlighted row, the Focus, Merge, Close and Unload buttons were black on black, so you only found them by hovering. They show as white buttons now.
- **View bar:** each of Tabs, Sites and Windows is as wide as its label, so a long count like "Windows 20" no longer gets cut off.
- **Double-click:** double-clicking a row, count or label no longer selects its text. The search field still selects as usual.

## Installing

ATO needs Chrome 157 or newer. The Chrome Web Store copy updates on its own. To build it yourself: `npm install && npm run build`, then load `dist/` as an unpacked extension.
