# ATO 3.1.1

The text around ATO now says what ATO does. Nothing about how it behaves changed.

This is also the first release of ATO 3 on the Chrome Web Store, which had 1.9.1.

## Name and summary

- The store summary was "Kill duplicate tabs instantly. Stay focused." It is now "Close duplicate tabs safely, see every window at a glance, and find any tab fast. Keyboard-first. No tracking, nothing collected."
- The toolbar tooltip was "ATO - Kill Duplicates". It is now "ATO - Advanced Tab Organizer".

## Store listing

- The keyboard paragraph matches the popup: it opens in search, where ⌘D reviews duplicates and ⌘⌫ closes; ↓ steps into the list, where single keys work.
- It says what is always protected (the current tab, tabs playing sound, split views) and what is protected by default (pinned and grouped tabs).
- The privacy text no longer says nothing leaves the browser. Favicons load from the addresses Chrome provides, and settings sync through your Chrome account if sync is on. ATO still has no analytics, tracking or backend, and collects nothing.
- The privacy policy and the `storage` justification now mention the undo record: the last close, kept in session storage until the browser closes.
- Discarded tabs are called "unloaded" everywhere, not "asleep".

## Updating from 1.9.1

- **Chrome will ask you to approve a new permission**, "View and manage your tab groups", and turns ATO off until you do. ATO uses it to show tab groups in the Windows view and to keep a group together when you merge windows.
- Your settings carry over.
- Tabs in a group are now protected by default. 1.9.1 left them unprotected unless you turned that on. If you turned group protection on or off in 1.9.1, your choice stays; either way it is under Settings.

## Installing

ATO needs Chrome 157 or newer. The Chrome Web Store copy updates on its own. To build it yourself: `npm install && npm run build`, then load `dist/` as an unpacked extension.
